Training losses by (t, r) bucket

Unweighted squared residual of the flow-map regression, per element, averaged over each bucket's samples in the global batch. The r = t bucket is plain flow matching, so it is the same quantity in both runs. For r < t the residual uses each run's own target (MeanFlow: data-velocity tangent; iMF: model-velocity tangent), so the curves show each objective's own fit; the samples below are the like-for-like comparison.
